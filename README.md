# DexAtlas · 灵巧操作术语图谱

以全屏 3D 图谱探索技术的工程位置与概念关系。内容库 **1.0.0 开发版**收录 64 个词条、101 条概念关系及 54 条工程用途；前端仍为 0.2.4。开发分支用于备份与审阅，尚未合并到 `main`，线上仍为已发布版本。

查阅 [来源与权威性评估](docs/source-authority.md)（[网页阅读版](docs/source-authority.html)）及 [内容核查记录与目录](docs/content-review-v1.md)。定义、作用、应用和条件分别保留证据定位；来源记录实际版本与适用边界。编辑核查不等于外部同行评审。

项目与版本备份仓库：[suyoutzy/DexAtlas](https://github.com/suyoutzy/DexAtlas)。本地 `main` 跟踪 `origin/main`，临时文件与 `node_modules/` 不纳入版本备份。

在线访问：[DexAtlas](https://suyoutzy.github.io/DexAtlas/)。

当前版本 **0.2.4**。默认均衡画质限制内部渲染像素、降低后处理开销，名称按需创建并缓存，全局静止和后台暂停刷新；保留默认发光 50 及既有三维交互。设置可切换高画质。性能测量方法和容量边界见 [性能报告](docs/performance-v0.2.4.md)。

## 本地预览

已生成的静态资源可直接通过 HTTP 预览：

```powershell
npm start
```

打开 <http://127.0.0.1:4173/>。也可使用 `python -m http.server 4173 --bind 127.0.0.1`。JSON 通过异步请求读取，请勿直接双击 HTML。

修改源码后使用 Node.js 20+ 构建：

```powershell
npm ci
npm run build
```

依赖版本由 `package-lock.json` 锁定，esbuild 将 Three.js、3D Force Graph 与 three-spritetext 打包到本地 `assets/`；运行时不请求第三方 CDN。

## 浏览与阅读

- 工程骨架以有前后深度的空间分布，大致从左到右阅读：目标、系统、方法、运行、评估、达成。默认视角下目标与达成等高，三个方法入口保持并列；整体仍可 Orbit 旋转。
- 工程节点拖动时跟随指针，松手后约 650 毫秒弹性回到原锚点；再次拖动会中断上次回位。减少动画模式下松手立即归位；术语节点继续自由拖动。
- 全部关系线使用直线，包括工程反馈连接；数据中的方向和含义仍可在阅读卡查看。
- 工程节点与流程线统一使用暖金色；C3 HTML 短标签带阶段编号并进行屏幕避让。术语保留青蓝紫粉分组色，使用同一字体系列的 C2 三维文字精灵。两类节点的名称均采用各自节点的基础配色。
- 滚轮缩放，点击术语约 600 毫秒聚焦，再查看按实际关系分组的浮动卡片。
- 相邻卡片先阅读；“以此词为中心”继续探索。关闭阅读卡回到局部关系，再次关闭保留当前镜头。
- 关系分组标题固定在滚动区域顶部，深色底保证亮光背景下仍可阅读；各组统一预留滚动条空间，卡片等宽。双击卡片外的画布空白收起概念、工程和阅读卡，保留聚焦与镜头；节点、连线及卡片上的双击不触发关闭。
- 右侧工具栏提供搜索、节点名称开关、查看全图和设置。名称开关默认关闭，工程短名称保留；聚焦与悬停显示各自节点和直接邻居的名称，开启时显示所有节点名称。
- 画布不显示关系文字；点击连接仍可阅读完整语义与出处，局部关系卡片上的关系说明也保留。
- 标签优先避让工程名称；视口确实放不下时暂不绘制无法安放的名称，可缩放或搜索定位，避免文字互相覆盖。
- 聚焦的 A3 高亮持续保留，悬停另一节点同时显示两者的直接邻域。仅高亮连线上有粒子；没有方向箭头。关系阅读卡保留双方顺序、语义和出处。
- 查看全图主动清除聚焦，按节点范围及当前观察方向取景；处于全图取景状态时再次点击，恢复目标在左、达成在右的正视图。手动旋转、缩放、平移或选择节点后重新从当前方向取景。加载只设置一次初始镜头，布局结束及窗口变化不取景。
- 全局状态下滚轮朝鼠标所在位置缩放；Orbit 支点随缩放移到新画面中心，不固定在整个图谱的节点中心。聚焦时仍围绕所选节点缩放与旋转。
- 按住滚轮中键拖动可平移整个图谱，也可从节点处开始；左键仍可旋转或拖动节点。
- 聚焦术语或工程节点后，手动向外缩小至全图相机距离的 60% 时，自动关闭卡片、清除聚焦，并保留当下构图、缩放与方向。阈值固定，不提供调节控件。旋转、平移、放大和自动飞行不会触发。
- 发光默认 50；设为 0 关闭 Bloom，刷新恢复 50。光晕集中于较亮图形附近，远处背景保持 #0A0B19。
- 画质默认“均衡”，内部倍率不超过 1、总像素不超过 1920×1080；“高画质”倍率不超过 1.5、总像素不超过 2560×1440。大窗口可低于 1 倍渲染，HTML 卡片与工程标签仍按浏览器原生清晰度显示；刷新恢复均衡。
- 两档均关闭后处理主缓冲的多重采样；均衡档额外降低 Bloom 输入尺寸。发光为 0 时移除并释放 Bloom，重新开启才创建；切换画质保留镜头和阅读上下文。
- 名称仅在需要显示且能在视口放下时创建。隐藏名称按最近使用顺序缓存，最多 64 个且 Canvas 像素数据合计不超过 8MiB，可见名称不受隐藏缓存上限限制。
- 全局无高亮动画且布局、镜头稳定时暂停绘制；输入唤醒后首次操作立即生效。聚焦／悬停连线粒子继续播放，页面进入后台时暂停，恢复后保留镜头。
- 首页保留图谱与品牌标识；简短用途和操作说明收进设置，两处装饰英文说明已移除。
- 搜索支持中文、英文、缩写与别名；`/` 打开搜索，方向键选择，Enter 定位，Esc 分层退出。浏览器后退与页面返回保留术语上下文。
- URL hash 可直接访问术语或工程环节。手机采用纵向关系卡与底部阅读面板；遵循系统减少动画偏好。
- 数据加载失败可重试；没有 WebGL 时仍提供搜索、词条列表、关系和来源阅读。

## 数据与实现

| 文件 | 职责 |
| --- | --- |
| `data/glossary.json` | 64 个词条、逐字段依据与唯一来源登记；原有术语 ID 不变。 |
| `data/annotations.json` | 101 条有出处的概念关系与沿革依据；保留历史论文案例数据，首页不使用该案例。 |
| `data/framework.json` | 9 个工程导航节点、13 条编辑性流程、54 个显式术语用途及依据。 |
| `data/content-audit.json` | 原样例重审与新增内容的机器可读记录。 |
| `src/atlas-model.mjs` | 三类连接、唯一术语节点、共用标签规则与直接链接解析。 |
| `src/model.mjs` | 搜索和概念邻域等可复用的数据逻辑。 |
| `src/graph-scene.mjs` | Orbit 相机、力导向布局、文字精灵、悬停与可选发光。 |
| `src/render-policy.mjs`、`src/render-pipeline.mjs` | 两档像素预算、renderer/composer 尺寸和 Bloom 生命周期。 |
| `src/resource-cache.mjs`、`src/term-labels.mjs` | 可见文字按需创建、邻接索引及隐藏文字缓存释放。 |
| `src/frame-scheduler.mjs` | 活动、空闲和后台状态，保留首个输入与高亮动画。 |
| `src/layout.mjs` | 工程空间锚点、方法分支、术语初始位置与拖动回位；不生成技术关系。 |
| `src/graph-view.mjs` | 排除标签的节点取景、固定阈值的缩小退出与全局／聚焦 Orbit 模式。 |
| `src/background-gesture.mjs` | 区分空白单击、双击及拖动打断，收起卡片时保留聚焦。 |
| `src/stage-labels.mjs` | C3 HTML 工程标签的相机投影与屏幕避让；不修改节点坐标。 |
| `src/app.mjs`、`styles.css` | 搜索、历史、关系浮层、阅读与响应式界面。 |

工程导航为“定义目标与验收条件 → 建立系统与接口 → 构建操作方法 → 部署与闭环运行 → 评估与迭代 → 达成验收条件”。方法构建提供设计与优化、从示范构建、从交互构建三个可组合入口，评估可反馈至方法构建。

该导航参考 [MIT Robotic Manipulation](https://manipulation.mit.edu/) 与 [LeRobot](https://huggingface.co/docs/lerobot/il_robots) 等课程和实现背景归纳，不宣称统一标准，也不表示所有技术组合都已实证。Isaac Lab 工作流文档保留为背景候选。仿真、采集、训练按方法说明，不作为所有路线的必经环节。

一个术语在全图只有一个节点，可被多个工程环节引用。`flow` 表示工程输入输出，`usage` 表示环节使用术语，`concept` 表示术语间概念关系。`from / to` 是记录方向，`label / explanation / evidence` 保存含义与出处。力导向距离及分类配色不生成技术关系；布局坐标不写入内容分类。沿革标签不等于性能或成熟度评分，依据不足时显示未评估。

论文能支撑具体任务与实现路线；六阶段顺序及全部箭头仍为编辑性导航。当前逐项依据与修订见 [内容核查记录](docs/content-review-v1.md)，旧版论证保留在 [工程依据历史记录](docs/engineering-evidence.md)。

## 验证

```powershell
npm test
npm run test:browser
```

浏览器检查使用开发环境已有的 Playwright 与 Chrome；`PLAYWRIGHT_MODULE` 可指定模块绝对路径，`PLAYWRIGHT_CHANNEL` 选择通道，`PREVIEW_URL` 指定预览地址。额外设置 `PREVIEW_SUBPATH_URL` 可检查仓库子路径，例如 `http://127.0.0.1:4174/DexAtlas/`，该地址需由父目录 HTTP 服务提供。网站运行不依赖测试工具。

测试覆盖规范节点、关系出处、搜索、预览与切换中心、返回、控制按钮、直接链接、真实 WebGL 交互、失败重试、无 WebGL 阅读、全部词条的桌面与手机布局、200% 文字和减少动画。截图在 `.work/screenshots/`。64 个词条的交互检查不代表更大规模图谱的性能结论；0.2.4 性能报告的原测量样本仍为当时的 22 个词条。

内容修改后运行 `npm run sync:relations`、`npm run check:content`、`npm run docs:content`。来源唯一登记在 `data/glossary.json`，其余文件只引用来源 ID；`related_terms` 从主关系表派生。`docs:content` 生成来源文档的 Markdown / HTML 与核查目录，脚本中的文档说明应随审核规则一起维护。

基础浏览器检查覆盖工程节点顺序、减少动画时松手立即回位、三个入口并列、Orbit 旋转、HTML 标签避让、悬停邻居名称和关系文字始终关闭。

附加检查覆盖聚焦与悬停邻域并集、空间锚点与等高端点、不同镜头比例的取景、固定 60% 的滚轮与触摸缩小退出，以及发光 0/1/25/50/100 的背景和局部光晕像素。空间布局验证真实拖动、中途回位、触摸取消、减少动画及直线连接的画布像素。真实 OrbitControls 输入事件及 Chrome 画布还验证鼠标位置缩放、随构图移动的旋转支点、节点处开始中键平移、工程节点缩小退出、两步全图取景、分组标题固定、卡片等宽和仅空白处双击收起。

性能基准使用开发环境已有的 Playwright、Chrome 和 Windows PowerShell：`npm run benchmark -- --ref v0.2.3 --output .work/metrics/v023-baseline.json` 测基线，`npm run benchmark -- --output .work/metrics/v024-balanced.json` 测当前源码。每项默认三轮，初始化 12 秒后每秒采样一次，共 30 秒。`npm run stress` 测确定性的 100／500／1000 词条模拟图。诊断专用构建才暴露测量对象，正式 bundle 不含诊断全局变量；原始数据位于忽略目录，不随网页发布。

## GitHub Pages

网站通过 [GitHub Pages](https://suyoutzy.github.io/DexAtlas/) 公开发布，发布源为 `main` 分支根目录，启用 HTTPS。推送到 `main` 后 GitHub 自动重新发布；修改源码或依赖后须先运行 `npm run build`，将生成的 `assets/` 一同提交。只修改 `data/` 中的 JSON 不需要重新打包。

`index.html`、`styles.css`、`favicon.svg`、`assets/`、`data/` 和 `.nojekyll` 均已纳入仓库。相对资源路径与 hash 状态适用于仓库子路径，术语直接链接可保留聚焦状态。发布不需要 `node_modules/` 和 `.work/`；两者均被 Git 忽略。依赖许可证随构建保存在 `assets/THIRD_PARTY_LICENSES.txt`。
