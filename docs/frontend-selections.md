## 主体与工程导航

网站以全屏 3D Force Graph 为主体。工程路线与概念关系属于同一画布的宏观与局部阅读层次；首页没有大型常驻说明面板。工程骨架采用通用导航，不再将特定论文案例作为首页主线。

定义目标与验收条件 → 建立系统与接口 → 构建操作方法 → 部署与闭环运行 → 评估与迭代 → 达成验收条件。方法构建有“设计与优化”“从示范构建”“从交互构建”三个可组合入口，分别连接部署，评估可反馈至方法构建。

这是参考 [MIT 教材](https://manipulation.mit.edu/)、[LeRobot](https://huggingface.co/docs/lerobot/il_robots) 和 [Isaac Lab](https://isaac-sim.github.io/IsaacLab/main/source/overview/core-concepts/task_workflows.html) 的编辑性导航，不宣称统一标准流程。仿真、采集、训练按所选方法说明。工程位置显式维护，同一术语全图只保留一个节点。

| 全局相机 | 非聚焦状态下，滚轮朝鼠标位置缩放，旋转支点随新的图幅中心移动，不固定在全体节点中心；聚焦后仍以所选节点为支点。按住滚轮中键拖动可平移整个图谱，也可从节点处开始。手动查看全图才重新按节点范围构图。 |
| A2 | 点击术语约 600 毫秒相机聚焦，关系卡片随后错开淡入；连续选择以最后一次为准。 |
| A3 | 聚焦与悬停均突出自身、直接邻居及连接，两者取并集。离开画布只清除悬停，保留聚焦；仅高亮连线有流动粒子。 |
| A7 | “查看全图”主动清除聚焦、关闭浮层，按节点范围与当前方向取景；处于全图取景状态时再次点击恢复目标在左、达成在右的正视图。手动旋转、缩放、平移或选择节点后重新开始两步操作。初始镜头只设置一次，布局结束和窗口变化不取景。 |

| C1 | 术语按现有 category_id 固定柔和青、蓝、紫、粉配色，不新增学术分类；工程节点与流程线使用专属暖金色。 |

| F1 | 0–100 发光滑条，默认与刷新值均为 50，设为 0 时移除并释放 Bloom，再次开启时创建唯一实例。保留线性渲染、统一输出颜色转换及正确背景清屏。 |
| 画质 | 刷新默认均衡：倍率≤1、像素≤1920×1080、Bloom 输入尺寸×0.5；高画质：倍率≤1.5、像素≤2560×1440、Bloom 输入尺寸×1。两档后处理主缓冲 samples=0，切换保留镜头、聚焦、卡片及历史。 |
| 文字资源 | 仅为可见且可安放的名称创建文字精灵；隐藏缓存按 LRU 限制为64项及8MiB Canvas数据，可见项保留。复用工程标签与引导线，状态不变时不重复写DOM。 |

节点名称开关关闭时，显示聚焦与悬停节点各自及其直接邻居的名称；开启时显示全部节点名称。可见工程节点的 C3 名称常显。两种状态都不在画布显示关系文字。

工程主线默认短名为“目标、系统、方法、运行、评估、达成”，方法入口为“设计优化、示范构建、交互构建”。完整名称保留在说明卡中。稳定的是各节点的世界坐标锚点，拖动只临时偏离；默认镜头的端点等高，整体旋转后的投影随观察方向改变。标签避让仅调整屏幕文字位置。

## 局部关系与阅读

保留“中心术语＋按关系分组的相邻卡片”，作为屏幕浮层。只显示已收录的直接关系，无对应关系则省略分组；每组先显示最多三项，其余主动展开。泛化相关说明折叠展示。

各组标题固定在本组滚动区域顶部，采用深色背景、细边与轻微模糊，保证背景亮光下的阅读对比度。各组统一预留滚动条空间，使卡片保持相同宽度；手机沿用外层纵向滚动。

中心卡显示名称与短定义，相邻卡显示名称与一句作用；点击卡片阅读完整说明，主动选择“以此词为中心”才切换主图。关系按钮与三维连线均可打开双方名称、完整含义与出处。

卡片外保留图谱旋转、缩放与点击。关闭阅读卡回到局部关系，关闭局部关系保留镜头与聚焦。双击画布空白收起概念、工程和阅读卡；保留当前聚焦、链接与镜头，不将节点、连线或卡片上的双击视作空白。提供关闭图标、上下文返回和 Esc 分层退出；术语与工程环节可直接链接。工程环节显示输入、输出、用途与来源。

## 视觉与适配

以用户提供的配色图为依据：背景 #0A0B19，洋红 #FF2FCF，青色 #1EF2FF。借鉴 Black Dashboard 的深色圆角卡片与渐变层次，用约 84% 不透明度深色底、局部模糊及低强度渐变边缘保持阅读对比度。

卡片标题约 20–24px，正文 18px，辅助信息不小于 14px；英文、来源和较长内容降低层级并收进展开区。右侧为低存在感图标工具栏：搜索、文字、全图、设置，返回按上下文出现；悬停与键盘聚焦显示提示。

手机保留三维主体，局部卡片纵向阅读，完整说明采用底部面板；点击节点承担按需显示。系统偏好减少动画时取消相机飞行、递进动画与松手回位动画，工程节点仍可随指针移动，松手立即归位。WebGL 不可用时提供可搜索、可阅读的词条入口。

## 数据与发布边界

保留原有 22 个词条及 32 条概念关系，新增 9 个工程环节、13 条工程流程及 29 个环节用途。三类连接分别为工程输入输出、环节使用术语、术语概念关系；均保存方向、含义与出处。数据与渲染分离，不由分类、空间距离或力导向位置推断连接。

采用静态 HTML、CSS、JavaScript 和独立 JSON，esbuild 生成本地依赖资源并锁定版本，运行时不依赖第三方 CDN。2026-10-19 按用户要求通过 [GitHub Pages](https://suyoutzy.github.io/DexAtlas/) 公开发布，发布源为 `main` 分支根目录；推送更新后自动重新发布。继续保留 22 个样例词条，不扩充完整术语库、不重写详细讲解。网站未来的具身领域覆盖范围与大规模性能仍待后续讨论。

论文补充核查、具体流程支持范围，以及手内操作在目标与评估处的两种用途，见 [工程依据记录](engineering-evidence.md)。六阶段和完整箭头仍为编辑性导航。
