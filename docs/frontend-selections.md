# DexAtlas 前端选配记录

更新日期：2026-10-17  
状态：本轮批准方案已实现为本地原型；保留 22 个样例词条，未公开部署。

## 主体与工程导航

网站以全屏 3D Force Graph 为主体。工程路线与概念关系属于同一画布的宏观与局部阅读层次；首页没有大型常驻说明面板。工程骨架采用通用导航，不再将特定论文案例作为首页主线。

定义目标与验收条件 → 建立系统与接口 → 构建操作方法 → 部署与闭环运行 → 评估与迭代 → 达成验收条件。方法构建有“设计与优化”“从示范构建”“从交互构建”三个可组合入口，分别连接部署，评估可反馈至方法构建。

这是参考 [MIT 教材](https://manipulation.mit.edu/)、[LeRobot](https://huggingface.co/docs/lerobot/il_robots) 和 [Isaac Lab](https://isaac-sim.github.io/IsaacLab/main/source/overview/core-concepts/task_workflows.html) 的编辑性导航，不宣称统一标准流程。仿真、采集、训练按所选方法说明。工程位置显式维护，同一术语全图只保留一个节点。

## 已实现的选配

| 项目 | 本轮决定 |
| --- | --- |
| A1、B1 | 三维力导向布局、节点拖拽与 Orbit 相机；不增加 DAG、固定路线排布、碰撞演示、多选或拖后固定。 |
| A2 | 点击术语约 600 毫秒相机聚焦，关系卡片随后错开淡入；连续选择以最后一次为准。 |
| A3 | 悬停突出当前节点、直接邻居及连接，仅高亮连线有流动粒子；离开画布清除悬停。 |
| A7 | “查看全图”主动清除聚焦、关闭浮层并取景；加载、布局结束和窗口变化均不自动取景。 |
| C1 | 根据现有 category_id 固定柔和青、蓝、紫、粉配色，不新增学术分类；工程节点区分环节与方法入口。 |
| C2、D5 | 文字精灵；节点与关系文字共用一个开关，默认关闭。 |
| D1、D2、D6 | 无方向箭头、普通连线持续粒子或点击发射粒子；数据方向在关系阅读卡中表达。 |
| F1 | 0–100 发光滑条；默认 0，关闭 Bloom 后处理；刷新恢复默认值。 |
| G1、G2、G4 | 异步 JSON 加载与失败重试，按展示状态更新数据与标签，响应式画布。 |
| G3 | 留待词条增加后验证容量和性能；不据当前样例作大规模保证。 |

文字开关关闭时，术语名称仅在被聚焦或悬停时出现；高亮邻居不自动显示名称。关系文字在任一端点被聚焦或悬停时出现。工程骨架保留短名称作为导航。开启时显示全部节点与连线文字。

## 局部关系与阅读

保留“中心术语＋按关系分组的相邻卡片”，作为屏幕浮层。只显示已收录的直接关系，无对应关系则省略分组；每组先显示最多三项，其余主动展开。泛化相关说明折叠展示。

中心卡显示名称与短定义，相邻卡显示名称与一句作用；点击卡片阅读完整说明，主动选择“以此词为中心”才切换主图。关系按钮与三维连线均可打开双方名称、完整含义与出处。

卡片外保留图谱旋转、缩放与点击。关闭阅读卡回到局部关系，关闭局部关系保留镜头与聚焦。提供关闭图标、上下文返回和 Esc 分层退出；术语与工程环节可直接链接。工程环节显示输入、输出、用途与来源。

## 视觉与适配

以用户提供的配色图为依据：背景 #0A0B19，洋红 #FF2FCF，青色 #1EF2FF。借鉴 Black Dashboard 的深色圆角卡片与渐变层次，用约 84% 不透明度深色底、局部模糊及低强度渐变边缘保持阅读对比度。

卡片标题约 20–24px，正文 18px，辅助信息不小于 14px；英文、来源和较长内容降低层级并收进展开区。右侧为低存在感图标工具栏：搜索、文字、全图、设置，返回按上下文出现；悬停与键盘聚焦显示提示。

手机保留三维主体，局部卡片纵向阅读，完整说明采用底部面板；点击节点承担按需显示。系统偏好减少动画时取消相机飞行与递进动画。WebGL 不可用时提供可搜索、可阅读的词条入口。

## 数据与发布边界

保留原有 22 个词条及 32 条概念关系，新增 9 个工程环节、13 条工程流程及 29 个环节用途。三类连接分别为工程输入输出、环节使用术语、术语概念关系；均保存方向、含义与出处。数据与渲染分离，不由分类、空间距离或力导向位置推断连接。

采用静态 HTML、CSS、JavaScript 和独立 JSON，esbuild 生成本地依赖资源并锁定版本，运行时不依赖第三方 CDN。当前不公开部署、不扩充完整术语库、不重写详细讲解。网站未来的具身领域覆盖范围与大规模性能仍待后续讨论。
