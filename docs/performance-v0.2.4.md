# 0.2.4 性能验证记录

测量日期：2026-10-19。基线为已提交的 `v0.2.3`，对照为本轮 0.2.4 源码。测试保留 22 个真实词条、9 个工程节点及全部 74 条连接，三份内容 JSON 未修改。

## 参考电脑上的内存对照

每个版本启动三个独立 Chrome 实例，逐个运行并在结束后关闭。两组均使用 Chrome 155.0.8059.80、硬件加速、AMD Radeon(TM) Graphics，经 ANGLE / Direct3D 11 渲染；CSS 视口为 1920×1080、设备像素倍率为 2，发光 50、术语名称关闭。初始化等待 12 秒，然后每秒采样一次，共 30 秒。表中每轮数值为该轮样本中位数，汇总值为三轮中位数。

| 指标（MiB） | 0.2.3 第 1 / 2 / 3 轮 | 0.2.4 均衡 第 1 / 2 / 3 轮 | 汇总变化 |
| --- | --- | --- | --- |
| 图形进程私有内存 | 2422.47 / 2427.06 / 2424.54 | 321.85 / 320.92 / 325.45 | 2424.54 → 321.85，下降 **86.7%** |
| 独立浏览器总私有内存 | 2693.44 / 2712.49 / 2697.42 | 559.73 / 562.80 / 560.14 | 2697.42 → 560.14，下降 **79.2%** |
| 浏览器各进程工作集之和 | 2850.49 / 2881.47 / 2882.50 | 776.12 / 768.86 / 771.77 | 2881.47 → 771.77，下降 73.2% |
| 页面 JavaScript 堆 | 12.03 / 12.22 / 12.19 | 10.79 / 12.83 / 10.80 | 12.19 → 10.80 |

图形进程私有内存下降达到本轮至少 60% 的目标。此结论仅对应上述参考环境、均衡档和测量协议，不能将 86.7% 表述为整个浏览器的降幅，也不能保证不同显卡、驱动或浏览器得到相同数值。

进程私有内存使用 Windows `PrivateMemorySize64`，表示进程专用提交量，不等同于显存，也不等同于实际驻留物理内存。浏览器总量为该次独立 Chrome 所有子进程的合计，不包含用户已有窗口；工作集合计可能重复计算共享页。JavaScript 堆由 CDP 单独读取。

| 图形资源 | 0.2.3 | 0.2.4 均衡 |
| --- | --- | --- |
| 主画布与 composer 缓冲 | 3840×2160 | 1920×1080 |
| composer 主缓冲多重采样 | 4 | 0 |
| Bloom 亮度提取目标 | 1920×1080 | 480×270 |
| 初始纹理 / 几何计数 | 13 / 5 | 13 / 5 |
| 初始术语 Canvas 像素数据 | 4,630,016 字节 | 0 |

Bloom 的输入尺寸先按均衡档乘 0.5，Three.js 内部亮度提取目标再减半。资源数量相同不表示内存相同，缓冲尺寸与多重采样才是本轮主要差异。优化版三轮在整个采样区间的绘制帧计数均保持不变；基线仍持续绘制。

## 画质与资源生命周期

- 均衡档：实际像素倍率不超过 1，总像素不超过 1920×1080，Bloom 输入尺寸倍率 0.5。
- 高画质档：实际像素倍率不超过 1.5，总像素不超过 2560×1440，Bloom 输入尺寸倍率 1。高画质不承担 60% 降幅指标。
- 实际倍率取设备倍率、档位上限、像素预算允许倍率的最小值。大窗口可低于 1 倍；CSS 布局、相机比例和鼠标位置不受内部倍率改变影响。
- 发光 0 时移除 Bloom 并释放渲染目标与材质；关闭期间切换画质不创建 Bloom，重新开启只创建一个。针对固定 Three.js 版本遗漏释放的高通滤镜材质额外执行释放。
- 文字在需要显示且可放入视口时创建。隐藏缓存同时受 64 项及 8MiB Canvas 像素数据限制，按最近使用顺序淘汰；可见文字不计入隐藏上限。
- 全局布局与相机稳定后停止绘制；首次点击、滚轮和中键平移可以唤醒。高亮粒子持续播放，后台暂停，恢复保留镜头与选择。

## 模拟图容量边界

仅供测试的确定性数据在诊断服务器中生成，不写入网站数据。术语数分别为 100、500、1000，另保留 9 个工程节点，连接数为 3N+13。测试使用上述浏览器和视口；名称关闭时先等待布局稳定，再测旋转与聚焦粒子期间的 60 个动画帧间隔。帧间隔反映该次合成负载，不等同于显示器实际呈现帧率。

| 术语数 / 名称 | 页面就绪 / 布局稳定（秒） | 活动帧间隔 中位 / P95（毫秒） | 图形 / 浏览器总私有内存（MiB） | 结果 |
| --- | --- | --- | --- | --- |
| 100 / 关闭 | 0.61 / 8.59 | 6.1 / 12.2 | 347 / 591 | 完成 |
| 100 / 开启 | 沿用上行已加载场景 | 24.2 / 30.4 | 686 / 951 | 完成；100 个可见文字 |
| 500 / 关闭 | 0.61 / 8.64 | 6.1 / 12.4 | 336 / 674 | 完成 |
| 500 / 开启 | 沿用上行已加载场景 | 未完成 | 860 / 1283 | 旋转步骤超过 25 秒超时，已达容量边界 |
| 1000 / 关闭 | 0.72 / 8.92 | 12.2 / 18.3 | 328 / 673 | 完成 |
| 1000 / 开启 | 沿用上行已加载场景 | 未完成 | 未取得有效样本 | 名称开关操作超过 30 秒超时，已达容量边界 |

100 名称测试关闭名称后，隐藏缓存保留 44 项、8,222,720 字节，满足两项预算。其余名称全开的超时样本不具备完整的性能指标，不使用关闭名称时的数据替代。

默认名称关闭时，模拟千节点图可以加载并完成测试；数百个名称全开仍有明显阻塞。隐藏缓存上限不限制当前可见名称的总量，不能解决所有名称同时显示的计算和贴图成本。此结果用于指导后续聚合、邻域显示或文字密度控制，不能据此承诺所有规模均流畅。本轮按既定范围保持全图展示。

## 回归检查与复现

逻辑测试与浏览器检查覆盖两档像素预算、20 轮发光与画质切换、关闭 Bloom 后不分配资源、空闲首个输入、后台恢复、销毁重建，以及现有搜索、导航、标签避让和手机阅读行为。背景与光晕继续检查发光 0 / 1 / 25 / 50 / 100；名称、卡片与来源数据保留原有规则。

```powershell
npm test
npm run build
npm run test:browser
npm run benchmark -- --ref v0.2.3 --output .work/metrics/v023-baseline.json
npm run benchmark -- --output .work/metrics/v024-balanced.json
npm run stress
```

浏览器脚本使用开发环境已有的 Playwright 与 Chrome；可用 `PLAYWRIGHT_MODULE` 指定 Playwright 模块路径。基准在 Windows 下另用 PowerShell 读取本次浏览器进程。诊断只在测试构建中暴露图形对象，正式资源不含诊断入口。原始采样、模拟数据结果与验收截图保存在忽略目录 `.work/metrics/`、`.work/screenshots/`，不随网站发布。
